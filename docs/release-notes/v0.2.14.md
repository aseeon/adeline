# Adeline 0.2.14

A bug fix release, mostly from a review of the whole codebase. All since 0.2.7.

## Before you upgrade

- **Remote machines can stay on 0.2.7.** The engine protocol hasn't changed, so 0.2.14 works with remote machines running 0.2.7. Updating them is still worth it, since many of the fixes below are in the engine.

## Fixes

### Chats

- **The open chat stays open when another chat arrives.** A new chat or fork from another window or computer moved the selection to a different chat, so the next message could go to the wrong conversation.
- **Probe and login agents stop when they're done.** Each agent check or login left its agent process running until the engine exited.
- **A message sent while the agent was busy is no longer lost** when the agent stops or crashes before taking it. It goes back to the queue.
- **A chat stays usable after a crash mid-write.** A half-written last line in its history made the chat read-only until the file was repaired by hand. Now that line is dropped.
- **A crash that mentions "auth" is no longer treated as a login problem.** Words like "author" or "OAuth", or an `auth.js` path in a stack trace, stopped retries and asked you to log in.
- **Quit with "Stop all" no longer hangs** when no machine is connected, and it no longer stops agents that another client is still using.
- **A crash while saving can no longer make a chat or project disappear.** Its settings file was briefly missing each time it was replaced.

### Docs

- **Edits made while a save is in flight stay unsaved**, so quitting still asks about them. Before, they were marked saved.
- **Edits keep counting after a failed rename** or after closing another project tab. Before, typing stopped marking the doc unsaved and Ctrl+S did nothing.
- **Saving a doc can no longer empty it.** A full disk or a crash during a save left the file empty. Saves now write a new file and replace the old one, keeping its permissions. Read-only files are refused with a message.
- **Saving a doc deleted on disk brings it back**, as the Save button promises.
- **A doc with wide spaces in a task list no longer crashes Adeline.**
- **Mermaid diagrams render once, in the background.** They redrew on every streamed reply, which made typing and scrolling stutter.
- **A failed reload after an agent edits the open doc shows a conflict**, so saving can't silently overwrite the agent's change.
- **Very large files no longer freeze every chat.** Files over 50 MB don't open.
- **A link in a project can no longer make a save write outside it.**
- **Links with spaces work**, such as `[notes](Notes%202.md)`.
- **UTF-16 text files open read-only** instead of being called binary.
- **Images in one project no longer show in another** when they share a path.
- **Save all no longer stalls** on a read-only doc.
- **Switching the .gitignore setting updates the tree** once the engine has the new setting, and a doc's open error no longer repeats its path.
- **The Docs and Chats panel separators match.**

### Settings and projects

- **Saving or deleting an agent no longer freezes the window** while a remote machine answers.
- **Deleting an agent keeps your other files** in its folder. It refuses instead.
- **Delete, rename and close act on the right project** even when the project list changes while a dialog is open.
- **Errors that were dropped now show**: MCP server saves, the engine switch, cancelling a project deletion, and Settings or agent windows that can't open.
- **A re-created project shows its own docs**, and Delete works in the projects menu.
- **A saved machine change that fails to save no longer shows as saved.**

### Remote machines and the engine

- **Terminal login works on Windows when a path has a space**, such as `C:\Users\John Smith`.
- **Two connections can install Adeline into one remote home at once.**
- **A client whose connection stalls is dropped and catches up when it reconnects**, instead of the engine holding its messages in memory for hours.
- **The engine no longer reloads every chat after its own writes**, such as marking a chat read.
- **The offline banner says changes can't be sent** until the machine reconnects, which is what happens.
- **A failed agent registry download is logged** with curl's error.

## Improvements

- **New shortcuts.** Ctrl+Tab and Ctrl+Shift+Tab switch project tabs, Ctrl+W closes one, Ctrl+O opens a folder, Ctrl+L focuses the message box, Ctrl+Shift+D dismisses a chat's errors, Ctrl+Shift+F forks at the latest reply, Ctrl+Shift+G opens a fork's source, and Alt+H (Cmd+Shift+H on macOS) opens the machines menu. Enter in the chat search opens the first match. Cmd works in place of Ctrl, except for switching tabs.
- **Tab works in dialogs and in Settings**, including the sidebar's group headers, and shortcuts keep working after a dialog closes.
- **Project tabs fold on Linux too.**
- **Faster memory allocation** with mimalloc, most noticeable for the engine on Linux.
- **Dependencies are checked for security advisories** on every build. This one updates rustls for four of them.
