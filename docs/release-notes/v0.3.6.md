# Adeline 0.3.6

The Redesign: Chats and Docs move to the new Islands design, with an optional Glass look, plus fixes for attachments, docs and engine safety. All since 0.2.20.

## Before you upgrade

- **Update remote machines to 0.3.6 too.** The engine protocol changed, so 0.3.6 doesn't work with remote machines running 0.2.20 or older.

## The Islands design

- **A new window layout.** The window is now a header and two floating islands around the chat. The left island holds the mode rail and the chat list, with the project switcher on top. The right island holds the side panel and its rail. Project tabs and the control bar are gone. The projects and machines menus open from the top center.
- **Islands and Islands Light themes.** Islands is the new default theme.
- **Docs mode matches.** The docs tree sits in the left island, the doc sits in a card with its own toolbar, and the chat moves to the right island. Ctrl+B and Ctrl+Shift+B (Cmd on macOS) show or hide the docs tree and the chat.
- **The right island resizes** from its left edge in every mode, up to twice its default width. Each mode remembers its own width.
- **Agent replies fill the chat column**, as wide as the composer.
- **Interface text defaults to 15 px** on new installs. Code stays at 14 px.
- **Menus and settings group their items under headings**, such as Agents and Settings in the main menu, and In the list and In chats for chat settings.
- **The window title centers on the main area** and stays clear of the window buttons.

## New

- **Glass.** Settings › General › Appearance › Glass blurs the desktop behind the window and the Settings sidebar. The islands and rails stay solid. It's off by default, and only on Windows and macOS.
- **Edit an agent** in the main menu opens the open chat's agent in Settings.
- **Ctrl+Shift+I (Cmd+Shift+I on macOS)** shows or hides the Activity tab of the side panel.
- **Task lists show in the Docs Viewer**, with checkboxes you can toggle.
- **Project images load in alerts and task bodies.** The remote images setting is gone, since it had no way to load remote images.

## Fixes

### Attachments

- **Files stay attached while a message is sending.** Before, they were cleared along with the sent ones.
- **An empty file sends as an empty attachment** instead of reporting that it has no content.
- **A queued message keeps its attachments** when you take it back to edit.
- **Linked attachments are copied into a private temp folder**, which is deleted when the agent closes.

### Docs

- **Docs reload when you enter Docs**, so changes made while it was closed show up.
- **A doc that changed on disk can't be saved over** until you resolve the conflict.

### Engine

- **The engine refuses to read docs and images that aren't regular files**, so a pipe can't block it.
- **Deleting a project frees its attachments and queued files** in the engine.
- **Saved agent traffic stays out of memory** and is read from the transcript when you watch it.
- **The Adeline config folder is owner-only on macOS and Linux** once the engine starts.

## Other changes

- "Submit on Enter" is now called "Send with Enter".
