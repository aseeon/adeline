# Adeline 0.1.0

This is the first release of Adeline, a native desktop app for running coding agents across your projects. It's built in Rust with GPUI and runs on Windows, macOS and Linux.

## Chats

Chats is the first mode in Adeline. Each chat is a conversation with one agent in one project. You can switch the model or effort level while you talk, and choose whether the agent asks before every action, runs reads on its own, or runs everything.

Next to the chat sits the activity panel. It lists what the agent did, one line per step: tool calls, how long each took, and whether it worked. Open a line to see its details. Hover it to light up the matching message in the chat. The panel also keeps a running count of tool calls, failures and tool time for the conversation.

## The Adeline engine

Conversations run in a separate background process called the engine. Agents keep working when you switch chats or close the window. If a turn is still running when you quit, Adeline asks whether to stop it or let it finish in the background. The reply is waiting when you come back.

You can open several windows and they all show the same live state. Adeline retries failed turns and restores interrupted sessions when the agent supports it. Every conversation is saved to disk.

## Projects

A project is a working directory with its own list of chats. When a chat is done, complete or archive it. That closes its agent and keeps the history.

## Agents

Adeline works with any agent that speaks the [Agent Client Protocol](https://agentclientprotocol.com) (ACP). Pick a harness from the ACP registry or point Adeline at any ACP command. We tested Claude Code, Codex, OpenCode and oh-my-pi.

Save an agent with a name, harness, model, effort level and default permission mode, then reuse it in any project. Agents and projects are plain YAML files under `~/.config/adeline/`. Edit them by hand and Adeline picks up the changes.

## Getting it

Download the zip for Windows (x86_64), macOS (Apple Silicon) or Linux (x86_64) from the [release page](https://github.com/aseeon/adeline/releases/tag/v0.1.0). To try a sample workspace without any agents, start Adeline with `--demo`.

Adeline is early. Expect rough edges and breaking changes. If something breaks, please [open an issue](https://github.com/aseeon/adeline/issues).
