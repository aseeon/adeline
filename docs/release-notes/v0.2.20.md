# Adeline 0.2.20

A small release with chat and agent activity improvements, a fix for OpenCode 2, and security updates. All since 0.2.14.

## Before you upgrade

- **Remote machines can stay on 0.2.14.** The engine protocol hasn't changed, so 0.2.20 works with remote machines running 0.2.14. Updating them is still worth it for the OpenCode 2 fix and the security updates.

## Fixes

- **OpenCode 2 is detected and installed.** With only OpenCode 2 installed, Adeline didn't find it, because its executable comes from the `@opencode/cli` package. Installing OpenCode now installs version 2.
- **Security updates** to tokio and rustls-webpki for RUSTSEC-2026-0382 and RUSTSEC-2026-0386.

## Improvements

### Chats

- **Adeline opens your last active chat** when it starts and when you switch project tabs. Before, it opened on Start a chat.
- **Code blocks in agent replies have a copy button**, shown while the pointer is over the reply. Ctrl+Shift+C (Cmd+Shift+C on macOS) copies the last code block of the latest reply.
- **New message bubbles.** User and agent messages share a bubble lit from above, with the corner next to the speaker squared off. The Reply, Copy, Fork and Retry icons are muted.

### Agent activity

- **An expanded row shows the whole command.** Clicking a tool call wraps its full command over as many lines as it needs, so long commands no longer hide in a tooltip.
- **Rows show a chevron** on the right that flips when the row expands or collapses.
