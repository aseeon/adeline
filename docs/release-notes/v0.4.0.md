# Adeline 0.4.0

The Changes Edition: a new Changes mode to review what an agent changed and comment on it, new themes, and a round of fixes. All since 0.3.6.

This is a pre-release. Changes mode has known bugs. If it gets in your way, turn it off in Settings › General › Features.

## Before you upgrade

- **Update remote machines to 0.4.0 too.** The engine protocol changed, so 0.4.0 doesn't work with remote machines running 0.3.6 or older.

## Changes mode

- **Review uncommitted changes in Adeline.** Changes sits on the mode rail after Docs (Ctrl+3 with the default modes). It compares the working tree with `HEAD` on the current branch, including staged, unstaged and untracked files. The project's engine runs git, so remote projects work too.
- **A tree of every file.** Changed files show their status color (added, modified, deleted, renamed) and their +A −D counts. Deleted files stay at their old path, and renamed files show where they came from. Ctrl+Alt+C shows only changed files, and Ctrl+F searches the tree.
- **Diffs from GPUI Kit.** A changed file shows its diff, unified or side by side (Ctrl+Shift+V, remembered). An unchanged file shows its whole text. Binary files and diffs that are too large say so.
- **Comment on lines or files.** Select lines and press Ctrl+Shift+N, or use the add button beside a line. Ctrl+Alt+M, a double-click or the right-click menu comments on a whole file. Each comment becomes a card in the message box, and a marker stays in the gutter. Click either to edit it.
- **Comments go out with your message.** When you send, the agent gets every comment with its path, lines and the quoted code, then your typed text. A comment keeps the lines as they were when you wrote it and says so if they change.
- **The chat stays beside you.** The right island shows a conversation, as in Docs, and Ctrl+Shift+K picks another.
- **A Changes summary in Chats.** The Activity panel shows the project's total +A −D. Clicking it opens Changes on the first changed file, with the same chat.
- **Live updates.** The tree, the diff and the counts follow edits on disk and commits made in a terminal.
- **Keyboard:** F8 / Shift+F8 move to the next or previous changed file, and F7 / Shift+F7 to the next or previous hunk. `docs/shortcuts.md` lists them all.

## New

- **New bundled themes:** Ayu, Catppuccin Latte and Mocha, Everforest, Gruvbox, Melange, One and Rosé Pine, each dark and light. They replace Astrovista, Catppuccin, LightOS, Optimus, Qrafthive and Zen Inspired. Your own themes are left alone.
- **A Ligatures switch** in Settings › General › Appearance, off by default.
- **Page Up and Page Down scroll the Docs Viewer.**
- **Alt+S (Cmd+Shift+S on macOS) opens the main menu.**
- **A plan list in Docs.** The TODO button and Ctrl+Shift+T open the agent's plan in Docs mode.

## Fixes

- **Escape hides the slash command list** until the message text changes.
- **"Send now" on an idle chat sends the queued message.**
- **A cancelled quit no longer lets later doc edits close unasked**, and after Discard the editor reloads the saved text.
- **Engine trouble on this computer shows a banner** while other machines are connected.
- **A consented engine upgrade that leaves the old engine running** reports the failure instead of asking again.
- **Token counts, durations and excerpts read right at their edges**, such as "1M" instead of "1000k".
- **Toasts are announced by assistive technology.**

## Other changes

- **Glass is gone.** Every window is opaque. A settings file with the old `glass` line still loads.
