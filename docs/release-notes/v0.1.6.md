# Adeline 0.1.6

This release adds a headless build of Adeline for servers, and support for ARM Linux remote machines.

## Headless build

Each release now ships a headless build next to the desktop zips:

- `adeline-headless-windows-x86_64.zip`
- `adeline-headless-macos-arm64.zip`
- `adeline-headless-linux-x86_64.zip`
- `adeline-headless-linux-aarch64.zip`

Each holds one `adeline` executable that runs `adeline engine`, `adeline bridge` and `adeline --version`, but has no window. It needs no desktop or GPU libraries, so it runs on a bare VPS or a home server with no desktop. The Linux builds are static and run on any distribution, Alpine included. `adeline --version` shows `(headless)` after the version.

## Remote machines

- When Adeline installs or upgrades itself on a remote machine, it now installs the headless build. A machine that already runs the desktop build of the same version is left as it is until the next upgrade.
- Linux ARM (aarch64) machines are now supported.
- Settings › Engine shows whether the selected machine runs the headless or the full build.

## Getting it

Download the zip for your platform from the [release page](https://github.com/aseeon/adeline/releases/tag/v0.1.6). Adeline is early. Expect rough edges and breaking changes.
