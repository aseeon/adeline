# Adeline 0.2.7

A bug fix release with two small additions. All since 0.2.4.

## Before you upgrade

- **Remote machines can stay on 0.2.4.** The engine protocol hasn't changed, so 0.2.7 works with remote machines running 0.2.4.

## Fixes

- **A project tab's close button closes the tab.** The click also reached the tab under the button, which opened the project again. Now the tab closes.

## Improvements

- **The project search matches machine names.** Type a machine's name to list the projects on it. Several words narrow the list to projects that match all of them, so "api devbox" finds the api project on devbox.
- **Add an agent from the Settings sidebar.** An "Add agent" row now sits below the agents in Settings.
