# Adeline 0.2.4

A bug fix release for the project tabs in the title bar. All since 0.2.2.

## Before you upgrade

- **Remote machines can stay on 0.2.2.** The engine protocol hasn't changed, so 0.2.4 works with remote machines running 0.2.2.

## Fixes

- **Project tabs fold again when the title bar runs out of room.** Since 0.2.2, the tabs stayed full width when the window was too narrow for them. They pushed the window buttons, the machine selector and the Projects menu off the right edge. Now inactive tabs shorten to three letters, then to their letter mark, and the rest move into the "+N" menu, as before.
- **The same fix with a screen reader.** With a screen reader or other accessibility tool connected, the tabs didn't fold at all. They now fold as they do without one.
