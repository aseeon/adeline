# Adeline 0.2.2

This release adds Docs mode: read, edit and discuss a project's docs next to a conversation with the agent. It also makes Adeline much lighter on the CPU while agents run, and fixes several bugs. All since 0.1.10.

## Before you upgrade

- **Remote machines need 0.2.2 too.** The engine protocol changed, so Adeline upgrades the Adeline on each remote machine when it connects. As before, it asks first if that machine's engine is running agents.
- **The ACP traffic view needs `--verbose`.** Start Adeline with `--verbose` to see the agent's raw ACP traffic in the side panel. Without it, the side panel shows only agent activity and Ctrl+Shift+L does nothing.

## Docs mode

A new mode on the mode rail shows the open project's docs: a tree on the left, the open doc in the middle, and a conversation on the right. It is on by default and can be turned off in Settings › Features. It works the same for projects on remote machines, and `--demo` has sample docs.

- **What counts as a doc.** Files ending in `.md`, `.markdown`, `.yaml`, `.yml`, `.toml` or `.txt`. Files your `.gitignore` ignores, and files in hidden folders, are left out unless you turn off "Respect .gitignore".
- **The tree.** Folders first, sorted by name, with fuzzy search by name and path (Ctrl+P). It updates by itself when the agent or anything else creates, renames or deletes a doc, and marks docs with unsaved edits. Create, rename (F2) and delete docs from it. Delete always asks first.
- **Viewer.** Renders Markdown the way GitHub does: tables, task lists, code with syntax highlighting, GitHub alerts (`> [!NOTE]` and the rest), front matter as a small table, and images by relative path. Mermaid diagrams render offline. A diagram that can't render shows its source and the reason. Clicking a task checkbox updates the file. Links to other docs open them in Docs, and heading links scroll to the heading. Remote images load only if you turn on "Load remote images".
- **Editor.** The raw text, with a toolbar for headings, bold, italic, strikethrough, code, links, lists, task lists, quotes, tables, and find and replace. Each tool has a shortcut. Switch between the Viewer and the Editor with Ctrl+Shift+V. YAML, TOML and plain text files get undo, redo and find and replace.
- **Saving.** Edits stay in memory until you save (Ctrl+S). Saving keeps the file's line endings. If a doc changes on disk while you have unsaved edits, Adeline asks whether to keep your version or take the one on disk. Closing a project or quitting with unsaved docs offers Save all, Discard or Cancel. Files over 10 MB, and files that aren't text, open read-only.
- **The conversation.** The right panel is a full chat. The chat's title is a chooser (Ctrl+Shift+K) that searches the project's chats and offers New chat.
- **Notes on a selection.** Select text in the Viewer and click "Note on selection", or press Ctrl+Shift+N in either view. The selection goes into the message box, quoted with the doc's path and line numbers, for you to add to before sending. A Mermaid diagram offers "Note on this diagram".
- **Doc cards.** When the agent creates or edits a doc during a turn, the reply shows a card for it, with Open and copy-path buttons. A reply shows up to 4 cards, and the rest fold into a list. Opening a card switches to Docs with that doc and that chat.
- **Remembered.** Per project, Docs remembers the open doc and its view, scroll position, panel widths, expanded folders and the chat on the right, across restarts.
- **Settings.** The Docs quick settings and Settings › Modes › Docs set which panels show, whether docs open in the Viewer or the Editor, "Respect .gitignore" and "Load remote images".

## Other improvements

- **Switch modes from the keyboard.** Ctrl+1 to Ctrl+9 (Cmd on macOS) switch to the modes on the mode rail, in order.
- **Quotes in your messages.** A paragraph of your message that starts every line with `>` shows as a quote, with a bar and muted text, like quotes in the agent's replies.
- **Selection stays in its panel.** A text selection you drag in one panel never spreads into text in another panel.

## Performance

- **Idle with agents running.** Running chats' animations are capped at 30 frames per second. With agents running and nothing else happening, Adeline's UI now uses about 12% of a CPU core instead of about 100%.
- **Streaming.** A reply being written redraws only its new text, and only the transcript and side panel redraw per chunk. The chat list and the rest of the window reuse their last drawing, as do hovering, typing and scrolling elsewhere.

## Fixes

- An agent or settings file with an MCP server can be read back again. Before, it failed to load.
- An engine killed mid-write could leave a broken line in a chat's transcript that blocked that chat. The chat now loads.
- On Linux, an agent that exits immediately is reported as exiting, instead of as a configuration error.
- If `machines.yml` can't be read, Adeline refuses to save machines instead of overwriting the file with an empty list.
- An interrupted download of Adeline to a remote machine is no longer reused on the next connect.
